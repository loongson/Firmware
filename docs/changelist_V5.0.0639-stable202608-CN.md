# Loongson UEFI Firmware Binaries for the Community (V5.0.0639-stable202608)

## 1. 版本概述

本版更新主要包含 PHY、MRC、SMC、PCIe、IPMI 等软硬件代码模块持续迭代升级、及 SPI/Variable、ACPI/SMBIOS、启动管理、显示与平台适配等更新，并进一步优化多节点平台稳定性、设备识别、启动性能及外设兼容性：

- **基础模块升级**：更新部分基础模块，完善龙芯 2K3000/3B6000M、3A5000、3A6000、3B6000、3C6000/S/D/Q 及 7A2000 等平台的支持；
- **平台支持增强**：新增 TD612D0（龙芯 3C6000/D 单路工作站）主板支持；
- **功能增强**：新增 eMMC 信息查询、默认开机密码配置、PCIe 设备序列号提取及基于安全引擎的随机数支持，并改进 ESP 启动项命名和显示初始化接口等；
- **稳定性与兼容性优化**：优化并修复 Variable、SPI Flash、PXE、GRUB 返回、Secure Boot 配置、ACPI、SMBIOS、显示、网络及存储模块中发现的相关问题，提升多节点启动和复杂 PCIe 拓扑下的稳定性与启动效率。

## 2. 基础模块升级

部分基础模块的具体版本及细节不在公开发布范围内，下表仅列出可公开说明的变化：

| 模块 | 基线变化 | 主要变化 |
|---|---|---|
| Loongson-FwSdk | 升级 V5.0.0639-stable202608 | 涵盖 2K3000/3B6000M/3A6000/3B6000/3C6000/S/D/Q 及 7A2000 芯片与平台相关升级 |
| IPMI 支持模块 | - | 修复部分界面配置、用户密码长度、和 BMC 端 SMBIOS/FRU 同步及 AC 上电循环稳定性问题 |
| 文件系统与模拟器模块 | - | 更新 Ext2 文件系统驱动，解决特定闭源 RAID 设备驱动缺陷规避读取数据异常问题 |
| EDK II（公共代码） | 沿用 stable202602 基线 | 尽量复用上游 HiiDatabaseDxe、VariableRuntimeDxe 及 VariablePolicyProtocol 等原始实现逻辑，减少代码冗余并保持和上游接口的一致性 |

## 3. 芯片与平台适配

### 3.1 2K3000/3B6000M 系列平台

- 新增 2K3000/3B6000M 笔记本平台 EDID 替换能力，可按项目配置适配不同 eDP 屏幕；
- 新增 2K3000/3B6000M 系列平台在 GPU 关闭时继续提供 DC 显示输出的支持；
- 完善 2K3000/3B6000M 平台 ACPI 事件、GPIO 及内存复位相关操作的处理；
- 完善 2K3000/3B6000M 平台 DisplayPort AUX 分包读写能力，以兼容部分 eDP 转换设备；
- 更新 X2K30B0 板卡的 VBIOS 显示配置,确保单通道 DP/HDMI 接口均可以点亮；
- 开放 2K 系列 ACPI.DSDT 内 LPC 节点的描述。
- 修复 2K3000/3B6000M 平台上 SMC 识别芯片类型错误问题；
- 修复 2K3000/3B6000M 平台 DisplayPort 间歇性读取 EDID 失败的问题；
- 修复 2K3000/3B6000M 平台 I²C 频率计算不准确的问题；
- 修复 2K3000/3B6000M 系列平台个别热重启场景下的电压调节判断行为，避免发生非预期调节。

### 3.2 3A6000 平台

- 重构桌面平台 I²C 电压调节功能，提升可维护性并优化日志输出；
- 优化 3A6000 平台个别场景下的 SMC 数据访问策略，兼顾运行稳定性和执行效率；
- 优化 3A6000 平台默认电压配置和异常输入提示；
- 优化部分原子操作；
- 修复 3A6000 系列桌面平台 SPI 双线模式配置及参数回滚时寄存器恢复不完整的问题。

### 3.3 3B6000 及 3C6000 平台

- 开启 3B6000 及 3C6000 系列平台 HPTW （Hardware PageTable Walk）页表遍历相关能力， 建议搭配 Loongnix Server 23.3 (Linux 6.6.52-1.12) 或主线 7.1.5 及以上内核版本使用；
- 新增 TD612D0 板卡支持，并同步完善相关 SMC 和构建配置；
- 新增 3B6000 及 3C6000 系列部分低频芯片定义识别；
- 优化 3C6000 多节点系统在个别重启场景下的从节点复位及节点间访问稳定性；
- 优化 3C6000 平台个别上电场景下的链路初始化稳定性；
- 优化 3C6000/D 平台内存参数，降低个别场景下 ECC 错误发生的概率；
- 优化部分原子操作；
- 完善 ACPI SRAT 处理（除 3C6000/S 双路拓扑），使处理器标识按实际核心索引生成；
- 优化 PCIe 训练关闭时的参数保存判断及相关链路配置，避免不合理参数影响；
- 修复 BMC 网页 (Web) 管理界面下 3C6000/S 及 3C6000/D 多路服务器机型内存温度显示及 CPU 数量识别不准确的问题；
- 修复 3B6000 平台启用 DVFS 后最高频率显示异常的问题。

### 3.4 7A2000 桥片

- 完善 7A2000 GPIO 操作接口，增加多位宽访问、输入状态和中断极性配置能力；
- 优化 7A2000 上游总线为 PCIe 时的 AHCI 顺序写性能；
- 修复 7A2000 PCIe 端口初始化控制问题，避免 GEN1 配置不生效。

### 3.5 板卡与外设

- **【重要】修复 XA612A0 板卡型号的 I²C 调压通道将核心电压设置过高的问题，建议正在使用 stable202602/05 版本的用户尽快更新到本版；**
- 新增 eMMC 信息查询、固件设置界面显示及专用启动项类型，完善 eMMC 启动项命名及无设备场景处理；
- 优化 Ext2 文件系统驱动，修复控制器卸载期间设备路径访问问题；
- 优化网卡初始化、PXE 开关和网络协议栈退出流程；
- 优化部分 PCIe 设备、NVMe 控制器和复杂 PCIe 拓扑下的识别、关闭及启动行为；
- 修复 QC622D1 （3C6000/S 双路）板卡型号蜂鸣器长响问题。

## 4. 通用（公共层）功能增强与优化

### 4.1 新增功能

- 改进 ESP 启动项命名，可从已知系统启动路径识别 Loongnix、UOS、Kylin、openEuler、deepin、Anolis、Arch Linux、AOSC OS 等操作系统；
- 新增或完善部分 ACPI ThermalZone `_STR` 描述，支持 3A6000/7A2000 温度传递节点；
- 新增基本信息界面的处理器线程数显示；
- 新增可配置的默认管理员密码能力（默认值为空时不启用默认密码）；
- 新增 ACPI EDAC 设备内存控制器索引和每节点控制器数量属性，便于 Linux EDAC 驱动识别对应节点与内存控制器；
- 新增 Secure Boot 配置模块的 LoongArch64 PE/COFF 镜像解析支持；
- 新增 PCIe 设备序列号读取能力，可用于补充 SMBIOS 设备信息；
- 新增初始化过程中 PCI 枚举时的 VID/DID 调试信息，便于设备识别和问题定位；
- 新增平台特定的可选策略，使 PCI Function 0 不存在时仍可继续扫描 Function 1-7；
- 新增基于龙芯安全引擎的 BaseRngLib 实现；安全引擎不可用时，可回退到 LoongArch64 架构随机数接口；
- 新增 ACPI IOVT 表有效 Proximity Domain 信息并补充 NUMA 拓扑描述，以提升 SRIOV 虚拟化调度性能；
- 启用 ResetRuntimeDxe 模块的 Reset Notification Protocol 支持，使 NVMe 等控制器可在系统复位前执行必要的关闭操作；
- 新增 SFDP（串行闪存可发现参数）解析功能，并按 Flash 页面优化写入的功能，可提高 UEFI 固件刷写速度（为不支持 SFDP 的设备保留了兼容路径）。

### 4.2 功能优化与调整

- 优化多节点平台 ACPI PCI I/O 资源描述，使各节点可根据节点数量使用适当的 I/O 空间；
- 完善安全引擎设备模式下的平台状态初始化功能；
- 重构 EFI 变量读写、管理功能实现并使用 EDK II 公共 VariableRuntimeDxe、FaultTolerantWriteDxe 及 VariablePolicyProtocol 组件实现，完善变量区和容错写入区域管理；
- 针对 PCI 子系统去除 NVMe 内部 OptionRom 加载，避免存在 x86 模拟和原生驱动冲突。
- 优化恢复默认配置时的启动超时处理，使其使用平台默认的启动超时配置；
- 优化 LoongArch64 固件镜像的段对齐策略及适用范围，使相关 PE/COFF 镜像满足页面对齐要求；
- 优化登临加速卡启动进度显示：减少重复画面刷新，降低复杂 PCIe 拓扑下的启动耗时；
- 优化管理员密码帮助信息，使其与实际长度限制保持一致，并增加超长输入提示；
- 移除 Legacy Boot（传统启动）选项中已不再支持的虚实地址切换模式，即不再支持旧版 BPI 接口规范；
- 更新 PCI ID 数据库至 2026-08-11，并补充部分尚未上游化登记的产品设备信息。

- 修复 Setup 界面下执行热键 F9/F10 后 PXE/HTTP 选项置灰问题。
- 修复固件设置界面中启用 PXE 后开关未生效的问题；
- 修复 PXE 驱动无法启动的问题；

- 修复 CMOS 恢复出厂设置时，在已设置管理员密码的场景下系统时间无法正常保存的问题；
- 修复 SMBIOS 中内存设备数量计算错误、NVMe 信息未生成及设备信息注册时序问题；
- 修复 BMC 用户密码长度配置与帮助信息中指引不一致的问题；
- 修复 SMC 参数表长度检查、频率校正、部分功耗配置组合、温度显示及 BMC 功能开关相关的一系列问题；
- 修复 IPMI BMC 显示配置访问在平台配置变化后可能触发启动时断言失败，导致引导失败的问题；
- 修复安全引擎的空实现中无效配置依赖可能触发启动时断言失败，导致引导失败的问题；
- 修复 SPI Flash 参数解析错误，可能导致的堆内存和 UEFI Variable 存储损坏的问题；
- 修复 ACPI 中断资源 `Exclusive`/`Shared` 属性使用不正确的问题；
- 修复图形输出局部画面偏移问题；
- 修复网络接口延时逻辑中使用循环延时导致的告警信息；
- 修复在 ExitBootServices 阶段调用部分网卡 UNDI 接口导致的连续报错；
- 修复固件设置界面保存确认结果传递不符合 EDK II 接口的问题；
- 修复 Secure Boot 配置模块中未初始化指针释放和回调路径内存泄漏问题；
- 修复驱动和平台库中的多处内存泄漏、无效依赖问题。

## 6. 注意事项

- 启用默认密码和过期提醒后，设备出厂超过设定周期时会显示提醒；
- 2K3000/3B6000M 平台 EDID 替换功能要求目标通道能够读取到有效 EDID 数据；
- PCI Function 0 缺失时继续扫描其他 Function 的能力为平台可选策略，默认行为由平台配置决定；
- HPTW 配套内核：3B6000/3C6000 平台启用 HPTW 后，建议搭配 Loongnix Server 23.3 (Linux 6.6.52-1.12) 或主线 7.1.5 及以上内核版本使用；
- PC 类产品在首次烧录固件并启动时，需要完成一次内存资源探测，期间可能触发首次重启策略，此现象属于正常行为，将在下一版本发布前探索修复方式；
- 主线内核 DVFS 驱动适配版本：本版仍作为社区预览发布，带有主线 DVFS 支持的固件镜像的文件名带有 `_mainline-dvfs` 后缀标识（如 `[...]_mainline-dvfs.fd`）；BIOS 设置界面显示的固件版本不体现 `_mainline-dvfs` 字样。
